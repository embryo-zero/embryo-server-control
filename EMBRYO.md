# Embryo Server Control

Embryo Server Control is Embryo-Zero's fork of [ipmitool](https://github.com/ipmitool/ipmitool) (be11d94, commit be11d94). It does server power and sensors over IPMI.

- Our changes live on the `embryo` branch. The original license files (COPYING) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
